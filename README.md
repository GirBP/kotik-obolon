# Котик за кермом — симулятор водіння Оболонню

Веб-гра: кермуй котиком-машинкою реальними вулицями Оболоні (Київ) на справжній
карті OpenStreetMap. Бери замовлення, заробляй, заправляйся на реальних АЗС,
стеж за пальним і бюджетом. Навчальний акцент — Правила дорожнього руху України.

Грати: <https://girbp.github.io/kotik-obolon/> — відкривається в будь-якому браузері
(iPhone, Android, комп'ютер), нічого встановлювати не треба.

Опис гри, механіки та прийняті рішення з причинами — [docs/DESIGN.md](docs/DESIGN.md).
Архітектура коду — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Журнал версій — [CHANGELOG.md](CHANGELOG.md).

## Керування

Телефон, дві руки: зліва повороти, справа газ і гальмо (у механіці ще —
зчеплення і передачі). Телефон, одна рука: авто саме тримає задану швидкість,
гравець лише кермує й гальмує. Комп'ютер: стрілки або WASD, `C` — зчеплення,
`Q`/`E` — передачі, `R` — завести двигун.

## Вимоги

- Node ≥ 18
- сучасний браузер для самої гри — мобільний пріоритетний, десктоп підтримується

## Збірка та запуск

```bash
npm install        # встановити залежності (раз)
npm run dev         # дев-сервер із HMR → http://localhost:5173
npm run build       # прод-збірка у dist/
npm run preview     # переглянути прод-збірку локально
```

## Тести й перевірка якості

```bash
npm test            # Vitest — юніти чистої логіки (гео, фізика, конфіг, стан)
npm run lint         # ESLint, 0 попереджень
npm run format       # Prettier
```

Перед комітом усі три команди мають бути зеленими. Робочий процес і правила
надійності коду — [CONTRIBUTING.md](CONTRIBUTING.md).

## Структура тек

- `src/core/` — стан, конфіг, гео-хелпери, аудіо-примітиви, фізика коробки передач
- `src/world/` — карта, дороги, POI, власний рендер світу
- `src/systems/` — ігрові підсистеми (радіо, поліція, світлофори, мультиплеєр,
  сліди сусідів, збереження та інші)
- `src/ui/` — HUD
- `src/main.js` — бутстрап і головний цикл гри
- `public/data/` — ігрові дані (дороги, POI, радіо, пасажири) як статичні JSON
- `test/` — Vitest-юніти чистої логіки
- `docs/` — дизайн-документ і архітектура коду

## Дані

Дороги, АЗС і храми — з OpenStreetMap (Overpass API), реальні координати
Оболоні. Ціни пального — ринкові дані 2026. Карта — Leaflet, тайли CARTO/OSM.

## Обмеження

Статичний застосунок без бекенду: мультиплеєр і сліди сусідів працюють через
публічні MQTT-брокери, best-effort, без гарантій доставки. 18 із 24 підсистем
зв'язуються між собою через `window.X`, а не ES-імпорти — див.
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
