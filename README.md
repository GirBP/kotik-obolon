# 🐱🚗 Котик за кермом — симулятор водіння Оболонню

Веб-гра: кермуй котиком-машинкою **реальними вулицями Оболоні** (Київ) на справжній карті.
Бери замовлення, заробляй, заправляйся на **реальних АЗС**, стеж за пальним і бюджетом.
Навчальний акцент — **ПДР України**.

**▶ Грати:** <https://girbp.github.io/kotik-obolon/> — відкривається в будь-якому браузері
(iPhone, Android, комп'ютер). Нічого встановлювати не треба.

## Що всередині

- 🗺️ **Реальна карта Оболоні** — дороги з OpenStreetMap; авто в реальному масштабі.
- 🛣️ **Режим руху:** «лише по дорогах» (авто тримається справжніх вулиць) або «будь-де».
- 🚗 **Ритуал старту як у житті:** вихід з дому → відмикання авто → **пристібання ременя** →
  запалювання → зняття з ручника → передача → поворотник → рушання.
- ⚙️ **Два режими КПП:**
  - **Автомат** — просто їдь;
  - **Механіка** — зчеплення, передачі R/N/1–5, оберти, **двигун глохне**, якщо рушати неправильно.
- ⛽ **Паливо й економіка:** бак 50 л, запас ходу, **8 реальних АЗС** (WOG, ОККО, KLO, SOCAR…)
  з цінами 2026; А-95 дорожчий за літр, газ дешевший, але витрата вища.
- 📦 **Заробіток:** замовлення з точки А в точку Б.
- ⛪ **Храми Оболоні:** візит дає гроші й «благословення дороги» (−15% витрати пального).
- 🌗 **Живий час:** реальний час і погода Києва — вночі котик вмикає фари, на мокрому
  гальмівний шлях довший.
- 📻 **Оболонь FM:** постійна районна радіостанція — джингли, рубрики, «Хвилинка ПДР»,
  діджей реагує на твою їзду.
- 👥 **Разом:** увімкни «Грати разом» і кермуйте вдвох в одній кімнаті.

## Керування

**📱 Телефон — дві схеми (кнопка ✌️/🖐️):**
- **Дві руки:** зліва ◀ ▶ повороти, справа **Газ** і **Гальмо**
  (у механіці ще: 🖐 Зчеплення і ▼▲ передачі).
- **Одна рука:** авто **саме розганяється** до заданої швидкості (кнопка **МАКС V**: 30/40/50/58),
  ти лише кермуєш ◀ ▶ і гальмуєш; після гальмування розгін відновлюється сам.

**💻 Комп'ютер:** `← ↑ → ↓` (або `W A S D`), `C` — зчеплення, `Q`/`E` — передачі, `R` — завести двигун.

## Дані

- Дороги, АЗС і храми — з **OpenStreetMap** (Overpass API), реальні координати Оболоні.
- Ціни пального — ринкові дані 2026 (див. `data/specs/` у робочій копії).
- Карта — [Leaflet](https://leafletjs.com/) + тайли CARTO/OSM.

## Технічне

Один файл `index.html` (HTML + CSS + JS, без збірки і бекенду) + `data/roads.json`
(417 відрізків доріг) і `data/pois.json` (8 АЗС, 7 храмів). Хоститься на GitHub Pages.

Локально: `python3 -m http.server 8000` у теці проєкту → відкрий `http://localhost:8000`.
