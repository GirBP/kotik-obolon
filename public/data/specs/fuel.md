## 2. Формула запасу ходу

```
range_km = (fuel_liters / consumption_L_per_100km) * 100
```

При 25 л (половина бака) → **≈310 км**.

## 3. Псевдокод виснаження пального (кожен тік симуляції)

```
function updateFuel(dt_seconds, speed_kmh, isCargoLoaded, isAC, drivingStyle):
    dt_hours = dt_seconds / 3600
    distance_km = speed_kmh * dt_hours

    baseRate = consumptionTable[drivingStyle]   // 7.0 / 8.0 / 9.5 л/100км
    if fuelType == LPG:
        baseRate *= 1.12                         // +12% на газі

    if isCargoLoaded: baseRate += 0.4
    if isAC:          baseRate += 0.3

    if speed_kmh > 0:
        fuelUsed = (baseRate / 100) * distance_km
    else:
        fuelUsed = idleRate_L_per_hour * dt_hours  // двигун на холостому ходу

    fuel_liters = max(0, fuel_liters - fuelUsed)

    if fuel_liters <= tankCapacity * 0.15 and not warningShown:
        showLowFuelWarning()
    if fuel_liters <= 0:
        stallEngine()          // авто глухне, місію по доставці провалено/штраф
```

## 5. Заправка на АЗС — UX

1. Авто в'їжджає в тригер-зону АЗС (полігон біля колонки) → з'являється підказка «Заправитись? [E]».
2. Відкривається панель заправки з логотипом мережі (WOG/ОККО/KLO/SOCAR), цінами по видах палива і трьома швидкими опціями:
   - **Повний бак**
   - **На всю готівку** (скільки грошей — стільки літрів)
   - **Вручну ввести літри/суму**
3. Анімація заливання: умовно ~0,5 сек гри за кожні 5 л (повний бак ≈ 5 сек), стрілка рівня пального на приладовій панелі рухається в реальному часі.
4. Після завершення — чек з сумою і списання коштів, авто отримує паливо.

**Псевдокод заправки:**

```
function refuel(station, fuelType, mode, value):
    pricePerLiter = station.prices[fuelType]
    maxAddable = tankCapacity - fuel_liters

    switch mode:
        case FULL_TANK:
            litersWanted = maxAddable
        case BY_MONEY:
            litersWanted = min(value / pricePerLiter, maxAddable)
        case BY_LITERS:
            litersWanted = min(value, maxAddable)

    cost = litersWanted * pricePerLiter

    if playerMoney < cost:
        litersWanted = playerMoney / pricePerLiter   // часткова заправка на всі гроші
        cost = playerMoney

    playerMoney -= cost
    fuel_liters += litersWanted
    playFuelingAnimation(duration = litersWanted / 10 * 1.0)  // сек

    return receipt(litersWanted, cost, station.name, fuelType)
```

## 7. Способи заробити

### а) Доставка/таксі на авто (між точками карти)
```
fare = baseFee + ratePerKm * distance_km
fuelCost = (consumptionRate/100) * distance_km * pricePerLiter
netProfit = fare - fuelCost
```
- **baseFee (посадка):** 25 грн
- **ratePerKm:** 14 грн/км (доставка їжі/посилок, таксі-пасажир — аналогічно)
- Приклад: поїздка 5 км → fare = 25 + 70 = **95 грн**, паливо (бензин 8л/100км, 76 грн/л) = 30,4 грн → чистий прибуток **≈64,6 грн** за ~10-12 хв гри.
- Швидкість руху в місті: 30–40 км/год → приблизна погодинна дохідність **≈320–390 грн/год брутто**.

### б) Заробіток пішки (кур'єрська доставка)
```
fare = 30 грн (до 1 км) + 15 грн за кожні наступні 500 м
```
- Швидкість ходьби: ≈5 км/год.
- Без витрат на паливо, ідеально коли бак порожній і грошей нема на заправку.
- Погодинна дохідність нижча: **≈130–150 грн/год**, підходить для коротких дистанцій (<1,5 км) або як «аварійний» режим заробітку.

### в) Порівняльна таблиця заробітку

| Спосіб | Швидкість | Дохід/год (брутто) | Витрати | Дохід/год (чистий) |
|---|---|---|---|---|
| Авто-доставка | 30-40 км/год | 320-390 грн | паливо ≈6 грн/км | ≈220-280 грн |
| Пішки | 5 км/год | 130-150 грн | 0 | 130-150 грн |

Авто вигідніше на дистанції, пішки — страховка при нульовому балансі/пальному.

### г) Бонус за візит до церкви

Раз на ігровий день (наприклад, кожні 24 хвилини реального часу = «ігрова доба») гравець може відвідати церкву на карті Оболоні (наприклад, храм в районі — сюжетна локація) і отримати:

- **+50 грн** «милостиня/пожертва навпаки» (одноразово за візит)
- Бафф **«Благословення дороги»**: −15% витрати пального протягом наступних **10 хв гри або 10 км** (що настане раніше)

```
function visitChurch(player):
    if player.lastChurchVisit < currentGameDay:
        player.money += 50
        applyBuff("blessing", fuelReduction = 0.15, duration_km = 10)
        player.lastChurchVisit = currentGameDay
    else:
        showMessage("Вже отримано благословення сьогодні")
```

Обмеження раз/добу запобігає фармінгу — бонус помірний і не ламає економіку.
