# План реалізації всесвіту · «Оболонь, яка живе»

> Як перетворюємо [PITCHES.md](PITCHES.md) на код. Кожна фіча проходить фільтр трьох
> стовпів канону ([UNIVERSE.md](UNIVERSE.md)): справжність місця, повага до дороги, тепло.
> Парасолькова ідея: **Оболонь живе, навіть коли ти вийшов з гри.**

## Принцип виконання

- **Архітектура:** гра — один самодостатній `index.html` (перевага для GitHub Pages).
  Нові підсистеми додаємо як **інлайн-модулі (IIFE)** з чітким контрактом хуків,
  контент виносимо в `data/*.json`. Моноліт розбиваємо на модулі поступово (борг з AUDIT).
- **Ролі моделей:** оркестрація/інтеграція/тести — головний цикл (opus);
  написання коду модулів і контенту — сабагенти (sonnet); механічна розвідка — haiku.
- **Кожен реліз — окремий деплой** з браузер-тестом і записом у CHANGELOG.

| 🤝 Сліди сусідів | мітки-подарунки, підвішена кава, гудок-привіт (MQTT retained) | **v0.6** |
| 🌙 Нічна зміна | нічні пасажири-новели з вибором тону | **v0.8** |

пауза + налаштування (звук/режим), звук двигуна. Робимо по дорозі, де блокує.

## v0.5 «Жива Оболонь» — ✅ ВИПУЩЕНО

### A. Київський час (атмосферний шар)
- Реальний київський час (`Intl`, timeZone `Europe/Kyiv`).
- Схід/захід і погода з **Open-Meteo** (без ключа); офлайн-фолбек: формула + ясно.
- Плавний тінт карти день → золота година → сутінки → ніч (читабельність збережено).
- **Фари** вночі (ПДР природно): котик вмикає сам, м'яка нотатка 💡.
- **Мокра/слизька дорога** (дощ/сніг) → довший гальмівний шлях (`LIVE.grip`); фізика вчить.
- HUD-чип: `🌙 23:14 · 🌧 +12°`.
- **Критерії приймання:** удень тінту нема; вночі фари + затемнення; при дощі гальмівний
  шлях помітно довший; HUD показує час/погоду; офлайн не ламає гру; перф ≤ поточного.

### B. Оболонь FM (seed ядра)
- Постійна станція (кнопка 📻 FM): джингл → рубрика (TTS) → пауза, по колу.
- Діджей реагує на події: заглух, заправка, храм, доставка, мало пального, ніч, дощ.
- Не конфліктує з локальним радіо Сенс/храм (глушиться, коли те грає).
- Контент — `data/radio.json` (канонічний тон), з інлайн-фолбеком.
- **Критерії приймання:** станція вмикається/вимикається; лінії озвучуються TTS;
  події дають доречні репліки без спаму (кулдаун); вимкнення при локальному радіо;
  стан on/off зберігається; без помилок консолі.

## v0.6 «Сліди сусідів» (наступний)
- Типи слідів: 📍 «звідси гарний захід», ⚠️ «обережно, яма», ☕ підвішена кава на АЗС,
  📣 гудок-привіт на перехресті.
- Транспорт: MQTT **retained** топіки `kotikobolon/traces/*` (без сервера); TTL за міткою часу.
- Модерація: **готові фрази**, не вільний текст (тепло без токсу).
- Потребує localStorage (мої сліди, отримані кави). → тут вводимо збереження.
- **Критерії:** мітку видно іншому гравцю в тій же зоні наступної сесії; кава передається
  рівно раз; спам обмежено; вимикається в налаштуваннях.

## v0.7 «Оболонь FM повна»
- Рубрики стають квестами (записати звук набережної, привезти гостя в студію).
- Дзвінки в ефір = генератор доставок (+ побутові квести «Двір-чату»).
- Прогрес станції замість «рівнів»; «Хвилинка ПДР» цитує пункт правил.

## v0.8 «Нічна зміна»
- 6–8 пасажирів-новел, вибір тону (мовчати/розпитати/підтримати), тижневий цикл.
- Активна вночі (Київський час) + ефір «Нічна зміна» на FM.

## Технічний борг, який гасимо по дорозі
- Збереження прогресу (localStorage) — у v0.6.
- Пауза + налаштування (звук/режим/чутливість) — у v0.5/раннє v0.6.
- Звук двигуна (муркотіння) — кандидат у v0.5.B чи v0.7.
- Модулізація index.html — коли файл перевищить керованість (зараз ~950 рядків).
