## Що це за гра

**«Котик за кермом»** — затишний симулятор водіння, у якому руденький котик їздить
**справжніми вулицями Оболоні** — з реальними проспектами, дворами, АЗС і храмами
з карти OpenStreetMap. Це водночас гра-іграшка та м'який тренажер
**Правил дорожнього руху України**: ремінь, смуги, знаки й повага до дороги тут —
частина світу, а не нудна теорія.

Гра зроблена як **подарунок** — з теплом, україномовна від першого пікселя,
відкривається за одним посиланням на будь-якому телефоні чи комп'ютері.
Нічого не треба встановлювати.

**▶ Грати:** <https://girbp.github.io/kotik-obolon/>

## Як це грається

Ти прокидаєшся вдома на Оболоні. Виходиш із під'їзду, підходиш до авто,
**клац** — ремінь, ключ у замок, ручник униз, передача — і місто твоє.

- **Їдь куди хочеш.** Проспект Івасюка на три смуги, тихі двори між панельками,
  набережна, озера. Хочеш — строго по дорогах і смугах, хочеш — вільний режим.
- **Заробляй.** Бери замовлення (посилка з метро «Оболонь» до Dream Town — 60 грн),
  вози, отримуй гроші.
- **Стеж за паливом.** Бак не безкінечний, а повний коштує як у житті (~3 900 грн А-95).
  Обирай: дорогий бензин чи дешевший газ із більшою витратою.
- **Заїжджай у місця сили.** Біля храму — дзвони і молитва по радіо. Біля книгарні
  «Сенс» — радіо з новинками й ефіром Стерненка. Благословення дороги економить пальне.
- **Грай удвох.** Введи спільну назву кімнати — і поруч їздитиме котик близької людини,
  зі своїм ніком над дахом.

Сесія — 5–20 хвилин. Без реклами, без донатів, без збору даних.

## Ключові особливості

| | |
|---|---|
| 🗺️ **Справжня Оболонь** | реальні вулиці, двори, 8 справжніх АЗС, 7 храмів — усе на своїх місцях |
| 🛣️ **Смуги і розмітка** | правостороння їзда, зміна смуги тапом, осьова та роздільники як на справжній дорозі |
| ⚙️ **Дві коробки** | автомат для відпочинку — або чесна механіка зі зчепленням, обертами і двигуном, який глохне |
| 🎮 **Керування під себе** | дві руки (газ/гальмо/повороти) або одна рука (авто само тримає швидкість) |
| 💰 **Жива економіка** | реальні ціни пального 2026, заробіток доставками, бюджет, який треба поважати |
| 🔒 **Ритуал водія** | ремінь, запалювання, ручник, поворотник — послідовність як у житті |
| 📻 **Радіо місць** | церковні дзвони з молитвою; радіо «Сенс» з ефіром з офіційного каналу Стерненка |
| 📻 **Оболонь FM** | постійна районна станція: джингли, рубрики, «Хвилинка ПДР», діджей реагує на твою їзду |
| 🌗 **Живий час** | реальний час і погода Києва: ніч → фари, дощ → довший гальмівний шлях |
| 👥 **Мультиплеєр** | кімнати за назвою — котики друзів на одній карті в реальному часі |
| 🇺🇦 **Українська повністю** | інтерфейс, диктор, молитва, назви вулиць — усе рідною |

## Для кого

- Для тих, хто **вчить ПДР** і хоче звикнути до дороги без стресу.
- Для пар і друзів — **спільні покатушки** своїм районом.
- Для оболонців — упізнати свій двір у грі.
- Для всіх, кому потрібні 10 хвилин затишку з котиком.

## Платформи

Веб (iPhone, Android, macOS, Windows — будь-який сучасний браузер).
Окремо існує нативний застосунок **«Котик ПДР»** (iOS/macOS, SwiftUI) з повною
навчальною базою ПДР: теорія, 46 звірених знаків, тести. Веб-гра і застосунок —
частини одного всесвіту (див. [UNIVERSE.md](UNIVERSE.md)).
